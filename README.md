## Описание
Это простейший плагин для IntelliJ IDEA, разработанный в рамках учебного задания.
Плагин добавляет в контекстное меню редактора кода новую команду **"Say Hello"**, которая выводит приветственное диалоговое окно.

## Возможности
- Добавление пользовательского действия (Action) в интерфейс IDE.
- Взаимодействие с контекстом IDE (проверка, открыт ли проект и редактор).
- Вывод системного диалогового окна (Messages).

## Пример использования
1. Откройте любой проект в IntelliJ IDEA.
2. Откройте любой файл (например, `.java` или `.txt`), чтобы активировать редактор.
3. Кликните **правой кнопкой мыши** в области редактора кода.
4. В самом верху контекстного меню выберите пункт **"Say Hello"**.
5. Появится всплывающее окно с текстом: *"Привет из моего первого плагина!"*.

## Сборка и установка
Для сборки плагина из исходного кода используется Gradle.
1. Клонируйте репозиторий.
2. В терминале выполните: `./gradlew buildPlugin`
3. Готовый ZIP-архив появится в папке `build/distributions/`.
4. Установите его в IDEA через `File -> Settings -> Plugins -> Install Plugin from Disk...`
