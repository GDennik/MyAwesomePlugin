## Описание плагина

**Demo1 — Say Hello** — это учебный плагин для IntelliJ IDEA, демонстрирующий базовые возможности разработки расширений на платформе JetBrains. Плагин добавляет в контекстное меню редактора кода пользовательское действие **"Say Hello"**, которое при вызове отображает приветственное диалоговое окно.

Проект создан в рамках учебы, не судите строго.

---

## Возможности плагина

### Основные функции
- **Пользовательское действие (Action)** — добавление кастомного пункта меню в контекстное меню редактора кода (`EditorPopupMenu`)
- **Контекстная проверка** — автоматическое включение/отключение действия в зависимости от состояния IDE:
  - Действие активно только при открытом проекте
  - Действие активно только при открытом файле в редакторе
- **Диалоговое окно (Messages)** — вывод информационного сообщения с иконкой через `Messages.showMessageDialog()`

### Технические особенности
- Реализация на Java (JDK 21)
- Использование IntelliJ Platform SDK
- Система сборки Gradle с Kotlin DSL
- Поддержка локализации через `ResourceBundle` (`messages.MyMessageBundle`)
- Пакетная структура: `su.dng.demo1`

## Установка и запуск

### Требования
- JDK 21 или выше
- IntelliJ IDEA (любая версия, совместимая с платформой)
- Gradle (используется встроенный wrapper)

### Сборка плагина
```bash
# Клонировать репозиторий
git clone https://github.com/GDennik/MyAwesomePlugin.git
cd demo1

# Собрать плагин
./gradlew buildPlugin
```

После сборки ZIP-архив с плагином появится в папке `build/distributions/`.

### Альтернативно: скачать готовый релиз
Если не хотите собирать плагин самостоятельно, можно скачать готовый ZIP-архив из [раздела Releases](https://github.com/GDennik/MyAwesomePlugin/releases) на GitHub. Выберите последнюю версию и скачайте файл `demo1-1.0.0.zip`.

### Установка в IntelliJ IDEA
1. Откройте IntelliJ IDEA
2. Перейдите: **File → Settings → Plugins** (Windows/Linux) или **IntelliJ IDEA → Preferences → Plugins** (macOS)
3. Нажмите кнопку ⚙️ (шестерёнка) и выберите **"Install Plugin from Disk..."**
4. Выберите собранный ZIP-файл из `build/distributions/`
5. Перезапустите IDE

### Запуск для разработки
Для отладки плагина используйте Gradle task:
```bash
./gradlew runIde
```
Это запустит отдельный экземпляр IntelliJ IDEA с установленным плагином в режиме разработки.

## Пример использования

1. Откройте любой проект в IntelliJ IDEA
2. Откройте файл для редактирования (например, `.java`, `.kt` или `.txt`)
3. Кликните **правой кнопкой мыши** в области редактора кода
4. В самом верху контекстного меню выберите пункт **"Say Hello"**
5. Появится информационное окно с текстом: *"Привет из моего первого плагина!"*

## Архитектура плагина

### HelloAction.java
Основной класс, наследующий `AnAction`:
- **`actionPerformed()`** — вызывается при нажатии пункта меню; отображает диалоговое окно
- **`update()`** — вызывается IDE для определения доступности действия в текущем контексте

### plugin.xml
Манифест плагина, содержащий:
- Уникальный идентификатор: `su.dng.demo1`
- Название и описание плагина
- Зависимости (`com.intellij.modules.platform`)
- Регистрация действия в группе `EditorPopupMenu` (якорь: `first`)
